# הקומץ – משחק אחוזים מולטיפלייר בעברית

שעשועון טלוויזיה בדפדפן: 10 שאלות היגיון מ-90% ועד 1%, אולפן תלת-ממדי עם במאי אוטומטי, מוזיקת מתח מסונתזת, מנחה אנושי או AI, ומענה בקול בעברית.

**להעלאה לאוויר ולשיתוף עם חברים: ראו [HOSTING.md](HOSTING.md).**

## הרצה מקומית
```bash
npm install
```
```bash
npm start
```
ופתחו http://localhost:3000

## מצבי משחק
- **מועדון:** 1 עד 100 מתמודדים, אפשר למלא עמדות ב-NPC. דילוג משאלת ה-50%, החלטה אחרי ה-5%, שיחות עם מודחים.
- **דו-קרב:** שני דוכנים, 3 חיים, תשובות סודיות שנחשפות יחד, נקודות מהירות, מוות פתאומי. שאר החדר צופים ומצביעים.
- **סולו:** טעות אחת וזה נגמר. לוח שיאים בדפדפן ובשרת.

## מבנה
```
server/
  index.js       Express + Socket.IO, API (config, leaderboard, tts)
  rooms.js       מכונת המצבים של המשחק: lobby → intro → question → answering → lock → reveal → elim → interview → decision → gameover
  questions.js   טעינת המאגר ובחירה ללא חזרות (לפי מזהה דפדפן + כינוי)
  store.js       שמירה ב-JSON (data/seen.json, data/leaderboard.json)
  script.js      ספריית הטקסטים של המנחה (טלפרומפטר + קריינות)
  ai.js          Claude לשיחות (אופציונלי), OpenAI TTS (אופציונלי)
  npc.js         מתמודדים וירטואליים
public/
  index.html, css/style.css
  js/main.js     ממשק, לובי, HUD, כתוביות, טלפרומפטר, מענה בקול
  js/studio.js   האולפן ב-Three.js (InstancedMesh, קרני אור, קונפטי, Bloom)
  js/director.js במאי אוטומטי: זוויות ותנועות מצלמה לפי מצב ושלב
  js/audio.js    מוזיקה ואפקטים ב-Web Audio (אפשר להחליף ב-mp3 ב-assets/music)
  js/voice.js    זיהוי דיבור he-IL והתאמה לאפשרויות (נרמול, מספרים במילים, התאמה מטושטשת)
  js/rtc.js      שמע WebRTC בין מנחה, מתמודדים ומרואיינים (signaling דרך Socket.IO)
  js/tts.js      קול המנחה AI
  js/images.js   איורי SVG לשאלות (שעונים, שלטים, לוחות, משולשים, משוואות צורות)
questions/
  level-XX.json  המאגר (463 שאלות, לפחות 41 בכל רמה)
  src/handwritten.js  שאלות שנכתבו ידנית
scripts/
  build-questions.js  בונה את המאגר (שאלות ידניות + שאלות שהתשובה שלהן מחושבת בקוד)
  test-flow.js        בדיקת זרימה מלאה עם כמה לקוחות בכל שלושת המצבים
  test-voice.mjs      בדיקות לזיהוי התשובות בקול
```

## בדיקות


## אבטחה מפני רמאות
התשובה הנכונה לא נשלחת לדפדפן עד רגע החשיפה. השרת בודק כל תשובה, וזיהוי הדיבור שולח לשרת רק את הבחירה (0-2). בדו-קרב, בזמן שהשאלה פתוחה, השמע בין שני המתמודדים מנותק בצד השולח ומושתק בצד המקבל.

הכסף במשחק וירטואלי לגמרי.
