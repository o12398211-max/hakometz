# מוזיקה מותאמת אישית (לא חובה)

המשחק מייצר את כל המוזיקה בעצמו (Web Audio). אם תרצו להחליף טראק בקובץ משלכם, שימו כאן קובץ mp3 בשם:

| קובץ | מתי מתנגן |
|---|---|
| `intro.mp3` | פתיחת התוכנית |
| `lobby.mp3` | לובי ומסך פתיחה |
| `tension.mp3` | בזמן שהשעון רץ (מומלץ קובץ שנשמע טוב בלופ) |
| `decision.mp3` | רגע ההחלטה אחרי שאלת ה-5% |
| `win.mp3` | חגיגת ניצחון |

השתמשו רק במוזיקה שיש לכם זכות להשתמש בה. אחרי הוספת קובץ, רעננו את הדף.
